MADBUX — install as an app
==========================
1. Upload this whole folder (all files) to any static host.
   Free options: app.netlify.com/drop (drag the folder), or GitHub Pages.
   You'll get an https:// link.
2. ANDROID: open the link in Chrome → ⋮ menu → "Install app" / "Add to Home screen".
3. IPHONE:  open the link in Safari → Share → "Add to Home Screen".
The app opens full-screen with the Madbux icon and works offline after first load.
Data is stored only on the phone. No account, no server, no network calls.
